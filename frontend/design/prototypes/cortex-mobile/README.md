# Cortex Mobile — phone UI kit

390×844 click-through of the same five views. The source app has no mobile design; this is the new one.

Decisions:
- Bottom tab bar replaces the sidebar; the five views keep their icons and order.
- Listings are cards, not tables — one entity per card, two-up metric tiles, full-width 44px action buttons.
- Everything the desktop toolbar holds moves into a bottom filter sheet (state chips, page size).
- Stopping a running process asks for confirmation in a dialog, naming the process.
- Pagination compresses to range + prev/next + "page n / m".
- The top bar drops the sync countdown and avatar; freshness moves to the page meta line.

Tap the filter button on any listing, and Stop on a running process, to see the overlays.

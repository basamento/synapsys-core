Short option list anchored to a trigger — page size, framework filter, row overflow. Active item gets the brand-soft tint, never a checkmark.

```jsx
<DropdownMenu trigger={<Button size="sm" variant="outline">10 / page</Button>}
  items={[{value:10,label:"10 / page",active:true},{value:25,label:"25 / page"}]} />
```

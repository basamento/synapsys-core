Every view starts with this: Bricolage display title, one muted meta line, actions on the right.

```jsx
<PageHeader title="Processes" meta="200 total · 10 on this page · polled 4 seconds ago"
  actions={<Button>Refresh</Button>} />
```

The meta line separates facts with `·`. Don't add a description paragraph — the meta line is the description.

Label · count · share bar. Builds the Process State and Worker Frameworks breakdowns on Summary.

```jsx
<MeterRow label="Running" value={2} total={10} tone="running" dot />
<MeterRow label="Spring Boot" value={1} total={1} />
```

Counts are mono; the bar is the same tone as the dot. Drop the bar (`showBar={false}`) in tight legends next to the donut.
